# Fortran_SD_Lab1
### Структура проекта

Каждая лабораторная работа 1_1 ~ 1_4 выполнена в четырёх вариациях:
- `_b` - базовая версия без OpenMP и без выравнивания данных;
- `_o` - версия с распараллеливанием средствами OpenMP;
- `_p` - версия с выравненными данными (адрес 1 элемента кратен 16 (средствами `allocate()`), все данные кратны 16 байтам);
- `_po` - оба метода вместе.

Для всех этих проектов входные данные находятся в одном месте. Эти данные содержат 1М студентов (строк).

Каждая лабораторная 1_5, 1_6a, 1_6b выполнена в 1 экземпляре. В папке data представлено два файла:
- `class.txt` - класс просто для проверки из 100 студентов;
- `class2.txt` - класс с максимальным количеством студентов для хвостовой рекурсии (до segmentaion fault).
Выбор файла производится в модуле `config.f90`.

### Немножко описательной части

Все проекты реализованы для `gfortran` и проверены на двух версиях: 13.3.0 и 12..

За корректность выполненной работы не ручаюсь. Сам прекрасно понимаю, что мои реализации вообще не векторизуются. Но распараллеливаются.
Для  распределения данных на потоки реализован метод разделения данных на куски, а не перебор данных с шагом в количество потоков.
